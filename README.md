# ATS System

Applicant Tracking System (ATS) is a web application that helps HR teams manage the recruitment process efficiently. The system allows users to create job postings, manage candidates, track applications, and schedule interviews through a centralized platform.

## Features

- User Authentication and Authorization
- Job Posting Management
- Candidate Management
- Resume Upload
- Application Tracking
- Interview Scheduling
- Dashboard and Reports
- Role-Based Access Control

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Installation

1. Clone the repository

```bash
git clone https://github.com/ruhul-akshay/Akshay-TalentAI.git
```

2. Install dependencies

```bash
npm install
```

3. Configure environment variables

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

4. Start the application

```bash
npm run dev
```
